# BOOM BOLTS ブリキロボの砲撃戦

Blastron（Kabam, 2013）の遊び方を再現したブラウザ版。名前と絵は自作。HTML1枚 + game.js、外部画像なし。

## 動かす

- 遊ぶ: `node server.mjs` → http://localhost:5190
- 全項目検証: `node verify.mjs`（55項目）
- 1場面撮影: `node shot.mjs <title|aim|aim-jungle|boom|tray|garage|result|lobby> [幅x高さ] [webkit] [touch]` → `検証/`
- 実時間で CPU 戦を連写: `node watch.mjs [枚数] [間隔ms]`

node_modules は ../ridgeline への symlink（playwright を使い回し）。

## 仕様（Blastron 準拠）

- 4体デスマッチ4分。1体ずつ交代、1ターン25秒、撃ったら残り5秒で逃げる
- 当てたダメージ×10点、撃破+500。水に落ちたら死亡、次の番に満タンで復活
- 左スティック移動・上でジャンプ／右スティックを狙う方向へ引く、長さが強さ（青→緑→黄→橙→赤）、離して発射
- PC: A/D 移動、Space/W/Enter ジャンプ（押す長さで高さが変わる・空中で左右に動ける）、ドラッグで狙って離す、↑↓ 角度 + F 長押し、1〜0 武器、Q/E 切替、ホイール/+- 拡大縮小、V か ミニマップ で全体表示、R 修理、P 一時停止、M 音
- 武器10種: ロケット/グレネード/ハンマー/跳ねボール/リボルバー/地雷/鉄球/火炎ボトル/テレポ弾/毒ガス
- 移動アイテム3種（番は終わらない）: ジェットパック（燃料3秒）/ワイヤーフック/パラシュート（落下ダメージなし）。元ゲームの具体名は資料で確認できず、Worms 系の定番で仮置き
- 補給箱（回復・弾・リベット）、修理ブースト2回

## ストーリー

- 物語: スクラップ島は人間が機械を捨てて去った島。電気は島の底の「大電池」だけ。昔は奪い合って戦争になり島が半分沈んだ。だから「4体ずつ順番に撃つ、壊れたら直す」大会で取り分を決める。毎年勝つガラクタは電気を受け取らず島じゅうに配っていた（元ブラウン管頭）
- 語り役: 修理屋ドック（真鍮のブラウン管・溶接ゴーグル・白いヒゲ・スパナ）
- チュートリアル「ドックの修理工場」: 歩く→跳ぶ→撃つ→武器替え→水に落とす→ルール説明。時間無制限・弾無制限。PC/スマホで文面を出し分け。初回 リベット+200

- 全5話。スクラップ島の砲撃大会。あなた（無口）、ポンコツ（相棒）、ネジマル（嫌味なライバル）、ガラクタ（無口な前回王者、元ブラウン管）
- 各話に目標（1体撃破/2位以内/1位）と初回クリア報酬。試合前の会話と、勝ち負けで変わる会話。保存は profile.story

## 演出

- 声: キャラごとの合成ロボ声＋頭上の吹き出し（当てた/撃たれた/吹き飛ぶ/撃破/かすめた/撃つ/番が来た/HP少ない）

- 表情: 待機・狙う・力む・叫ぶ・喜ぶ・ドヤ顔・×目・怯え・不安（汗）・毒（ぐるぐる）・しょんぼり。ブラウン管の画面に出る
- 余韻: 弾が落ち着いてから1.2秒、撃破のあとは2秒映す。撃破は0.75秒スロー
- 背景: ステージごとに多層の遠景（キャニオン=台地・煙突の工場・クレーン・岩柱 / 浮島=霧の山・滝・ヤシ林・光の筋・鳥）、雲、漂う粒
- 置物: サボテン・ドラム缶・看板・ヤシ・シダ・キノコ・ツタ等。足場が崩れると落ちる
- 音: BGM（タイトル/試合、残り5秒で刻みが増える）と効果音約30種、すべて WebAudio で合成
- ミニマップと画面外の敵の矢印（距離つき）

## 育成

- 頭・胴・脚 各4パーツ（ランク1〜4）。能力値は 攻撃/装甲/HP/ジャンプ/速さ。強化3段階
- 通貨: リベット（当てる・撃破・順位・箱）、ギア（勝利・レベルアップ）
- 経験値でレベル。レベルで武器とパーツのランクが解放
- 保存は localStorage `boombolts.v1`。使えない環境でも遊べる（保存されないだけ）
- CPU はプレイヤーのレベルと強さ設定に合わせたパーツを持つ
